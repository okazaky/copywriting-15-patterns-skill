# Pattern 03: 自己投影クエスチョン (Self-Reflection Question)

Cluster: Reader Anchoring

## Effect

問い返しは、読者を「他人事」から「自分の話」に引き戻す。鏡をそっと差し出す動き。

## Best For

- 課題喚起・自覚化
- 行動変容を促すコピー
- 共感を入口にしたい時

## Prompt Template

`「{{theme}}」について、読者が一瞬手を止めて自分に当てはめる問いかけ型コピーを10案出す。`

## Shape

- `…って、自分のことだなと思ったことありませんか`
- `本当に欲しいのは{X}じゃなくて{Y}では？`
- `今のままで、半年後の自分は喜びますか`

## Quick Example

- `「忙しい」と言いながら、本当に詰まっているのは時間ではなく判断ではありませんか。`
