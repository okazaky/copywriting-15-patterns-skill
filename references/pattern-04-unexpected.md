# Pattern 04: 反転トリガー (Reversal Trigger)

Cluster: Curiosity Gates

## Effect

期待される結論をひっくり返してスクロールを止める。「いつもの王道」ではなく「実はその逆」を提示する。

## Best For

- 注意を1秒で奪うX投稿の冒頭
- 業界の常識に切り込む見出し
- 思考停止しているテーマの再起動

## Prompt Template

`「{{theme}}」について、王道の答えをひっくり返した形のコピーを10案出す。`

## Shape

- `多くの人が信じている{X}は、実は{反対}が正しい`
- `頑張るほど遠ざかる、{テーマ}の落とし穴`
- `{常識}より{逆方向}が効く理由`

## Quick Example

- `努力で伸びると思っているうちは、伸びない。`
