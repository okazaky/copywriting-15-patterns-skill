# Pattern 09: 対比軸 (Contrast Axis)

Cluster: Specificity

## Effect

「Aが良い」と単独で書くより、「BよりA」と並べる方が記憶に残る。比較が選ぶ手間を肩代わりしてくれる。

## Best For

- ポジショニング訴求
- 旧手法を退ける新手法の紹介
- 価格訴求・買う側の決め手作り

## Prompt Template

`「{{theme}}」について、AとBを対比して片方の優位を伝えるコピーを10案出す。`

## Shape

- `{古いやり方} ではなく {新しい設計} の話`
- `{表の選択肢} と {裏で使われている本命} の違い`
- `{頑張る} 人と {仕組む} 人で、半年後の差はここ`

## Quick Example

- `がむしゃらな人と、設計図を持っている人。半年後にいる場所が違う。`
