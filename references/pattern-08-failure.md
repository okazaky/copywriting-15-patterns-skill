# Pattern 08: 落とし穴開示 (Pitfall Disclosure)

Cluster: Narrative Push

## Effect

ポジティブな約束より、「これをやると詰む」型の方が刺さりやすい場面がある。損失回避バイアスを正しく利用する。

## Best For

- 警告系・注意喚起の記事
- ノウハウの誤用パターン解説
- 「やめるべき」リスト系

## Prompt Template

`「{{theme}}」について、これをやると失敗する/損するという形でコピーを10案出す。`

## Shape

- `{行動}をしている人ほど、{逆の結果}を招いている`
- `見落としがちな{N}個の地雷`
- `頑張っても結果が出ない人がやめられない{習慣}`

## Quick Example

- `毎日努力しているのに伸びない人は、たいてい同じ三つの地雷を踏んでいる。`
