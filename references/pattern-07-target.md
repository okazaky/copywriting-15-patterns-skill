# Pattern 07: 宛名ロック (Audience Lock)

Cluster: Reader Anchoring

## Effect

「あなた向けです」と書くより「{この属性}の人向け」と限定する方が、当該読者の自分事化が一気に進む。同時に、合わない層を入口で外す副作用も得られる。

## Best For

- 高単価・限定オファー
- ニッチセグメント向けLP
- ペルソナを明確に切りたい採用記事

## Prompt Template

`「{{theme}}」について、対象読者を一行で限定して呼び込むコピーを10案出す。`

## Shape

- `{属性}で{状況}の人にだけ届けたい`
- `{初級者は除く}、{次のステージ}を探している人へ`
- `{年齢層}の{職種}が直面する{固有の壁}を持っているなら`

## Quick Example

- `年商一億の壁で半年止まっている、ひとり経営者にだけ。`
