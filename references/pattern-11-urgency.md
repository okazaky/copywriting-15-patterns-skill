# Pattern 11: 時限プレッシャー (Time Pressure)

Cluster: Narrative Push

## Effect

時間の有限性を一行に乗せると、判断が「今でなくていい」から「今しかない」に切り替わる。締切を捏造しないことが信頼の前提。

## Best For

- ローンチ・募集締切
- 期間限定オファー
- 行動が遅れがちな読者へのCTA

## Prompt Template

`「{{theme}}」について、時間の有限性を感じさせるコピーを10案出す。`

## Shape

- `この機会を逃すと、次は{N}ヶ月後`
- `差が開くのはいつも{時期}`
- `決められない時間そのものが、{損失}になっている`

## Guardrail

実在しない締切や残席数を書かない。期日が無いテーマでは「相対的な遅れ」だけを語ること。

## Quick Example

- `決められない時間そのものが、半年分の遅れを作っている。`
