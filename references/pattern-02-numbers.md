# Pattern 02: 数値アンカー (Numeric Anchor)

Cluster: Specificity

## Effect

抽象を一つの数字で固定すると、読者の頭の中に「重さ」が生まれる。何でもいい数字ではなく、信じやすい桁・期間・件数を選ぶ。

## Best For

- 工数・期間・成果の訴求
- 比較・ランキング系
- ノウハウまとめ系

## Prompt Template

`「{{theme}}」について、数字を一語入れて重みを出すコピーを10案出す。`

## Shape

- `たった{N}分で`
- `{N}人が{動詞}した`
- `{N}年やってわかった`

## Guardrail

ユーザーが提示した実数値、または明らかに構造的な数字（3つの理由、5ステップ等）以外は捏造しない。

## Quick Example

- `たった14分で、明日のコピー案が10本そろう。`
