# Pattern 13: 等身大宣言 (Equal-Footing Declaration)

Cluster: Emotional Hooks

## Effect

書き手が一段下がる（自分を褒めない・笑える形で見せる）ことで、読者は警戒を解いて読み始める。卑下ではなく等身大。

## Best For

- 個人発信・クリエイター系SNS
- 学びの過程を共有する記事
- 失敗からの再起ストーリー

## Prompt Template

`「{{theme}}」について、書き手の弱さや遠回りを軽く混ぜたコピーを10案出す。`

## Shape

- `頭の悪い私が{N}年かけてようやく辿り着いた答え`
- `不器用なまま続けた結果、こうなった`
- `センスゼロの自分でも回せた{仕組み}の話`

## Quick Example

- `センスゼロの自分が、半年だけ真面目にやって辿り着いた一つの結論。`
