# Pattern 14: 検証ナラティブ (Verification Narrative)

Cluster: Specificity

## Effect

「やってみた」「測ってみた」「比べてみた」と検証プロセスを匂わせると、主張が「意見」ではなく「観測結果」のトーンに変わる。権威を借りず、自己検証で信用を作るパターン。

## Best For

- 比較レビュー・検証系記事
- ケーススタディ
- 分析的なX投稿

## Prompt Template

`「{{theme}}」について、検証や実測のニュアンスを伝えるコピーを10案出す。`

## Shape

- `{N}回試してわかった、{テーマ}の本当の効きどころ`
- `実測してみたら、{予想}とは逆だった`
- `{期間}ずっとログを取って初めて見えた話`

## Guardrail

実測していない数字や、検証していない主張に「検証した」というトーンを与えない。

## Quick Example

- `30件のLPを実測比較してわかった、刺さるコピーの最小単位。`
