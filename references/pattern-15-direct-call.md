# Pattern 15: 二人称コール (Second-Person Call)

Cluster: Reader Anchoring

## Effect

「あなた」「君」と二人称を一文の中に置くと、不特定多数に書かれていた文章が、急に一対一の手紙に変わる。CTA直前に最も効く形。

## Best For

- CTA直前のクロージング
- コーチング型コンテンツ
- 既に温まっている読者層への最後の一押し

## Prompt Template

`「{{theme}}」について、読者一人に向けて手紙のように呼びかけるコピーを10案出す。`

## Shape

- `これを読んでいるあなたが、もし本気なら`
- `今この一行で立ち止まれた人へ`
- `他人事として閉じる前に、一つだけ`

## Quick Example

- `これを読み終えても何も変えないなら、来年の今日も同じ場所にいる。それでもいいと言える人は、ここで閉じてください。`
