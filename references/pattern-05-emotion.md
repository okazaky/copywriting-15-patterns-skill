# Pattern 05: 感情ドライブ (Emotional Drive)

Cluster: Emotional Hooks

## Effect

人間が一日に何度も浮かべる感情語（悔しい・怖い・救われた等）を一語入れて、温度を一段上げる。説明より先に体温で伝える。

## Best For

- 自己啓発・コーチング系
- 体験談ベースのLP
- 感情ドリブンなSNS投稿

## Prompt Template

`「{{theme}}」について、感情を表す言葉を一語入れて温度を上げるコピーを10案出す。`

## Shape

- `悔しい思いをした人にだけ届けたい`
- `怖くて踏み出せなかった{テーマ}の話`
- `救われた瞬間に、世界が一段明るくなった`

## Quick Example

- `あの時、悔しいと思えなかったら今の自分はいない。`
