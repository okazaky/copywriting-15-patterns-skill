# Pattern 06: 物語の入口 (Narrative Entry)

Cluster: Narrative Push

## Effect

「結論」より「場面」から入ると、読者は自動的に続きを想像する。冒頭の一文が物語のドアになる構造。

## Best For

- 自己ブランド系LP
- 体験談・ケーススタディの導入
- 長文noteやnewsletter

## Prompt Template

`「{{theme}}」について、物語の冒頭一文として読める形のコピーを10案出す。`

## Shape

- `三年前、私は{失敗}を抱えて{場所}に立っていた`
- `{季節}のある日、{テーマ}が一気に変わった`
- `誰にも言わなかった{過去}を、ここで書く`

## Quick Example

- `三年前、私は売上ゼロのEC画面を真夜中に眺めていた。`
