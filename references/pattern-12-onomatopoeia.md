# Pattern 12: 音感ワード (Sonic Word)

Cluster: Emotional Hooks

## Effect

擬音・擬態語を一語入れるだけで、文章の温度・スピード感・体感が変わる。論理ではなく耳で記憶される側に切り替わる。

## Best For

- SNS投稿の冒頭
- カジュアルなLPの見出し
- リズムで覚えてほしいキャッチ

## Prompt Template

`「{{theme}}」について、擬音・擬態語を自然に一語入れて体感を伝えるコピーを10案出す。`

## Shape

- `{テーマ}が、ふっと軽くなる瞬間`
- `じわっと効いてくる{結果}`
- `カチッとハマる{仕組み}の話`

## Quick Example

- `売上の壁が、ふっと一段下がる瞬間がある。`
