# Pattern 01: 禁忌ゲート (Forbidden Gate)

Cluster: Curiosity Gates

## Effect

「読むな」「やるな」と門を閉じることで、逆に通り抜けたい衝動を生む。カリギュラ効果を入口設計に使う。

## Best For

- 入口で読者を選別したい時
- ニッチ層への鋭いフック
- 高単価・限定商材の見出し

## Prompt Template

`「{{theme}}」について、読者に「やるな・読むな」と門を閉じる形のコピーを10案出す。`

## Shape

- `この記事、◯◯な人は閉じてください`
- `下手に試さないでください`
- `知ってしまうと戻れないので注意`

## Quick Example

- `軽い気持ちで始める人は、ここから先は読まないほうがいい。`
